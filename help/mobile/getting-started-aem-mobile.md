# Introducción a Adobe Experience Manager Mobile{#getting-started-with-aem-mobile}

{{ue-over-mobile}}

>[!CAUTION]
>
>Los clientes existentes de aplicaciones móviles de Adobe Experience Manager (AEM) que migran de AEM 6.2 o 6.3 a AEM 6.5 pueden seguir utilizando aplicaciones de AEM Mobile descargando un paquete de Uso compartido de paquetes. Sin embargo, las nuevas instalaciones de AEM 6.5 no admiten la funcionalidad de aplicaciones de AEM Mobile.

AEM Mobile forma parte de la plataforma digital multicanal de Adobe Experience Manager que también utiliza AEM Assets, Sites, Screens, Workflow, User Manager, Commerce y Forms. AEM Mobile ofrece una notable flexibilidad de implementación, lo que permite a las empresas utilizar varias fuentes de contenido.

AEM Mobile ofrece varios métodos para crear aplicaciones. Las tres formas diferentes de crear aplicaciones son las siguientes:

* **[Uso de On-Demand Services con AEM](/help/mobile/getting-started-aem-mobile-on-demand.md)**
* **[Usar On-Demand Services sin AEM](https://helpx.adobe.com/digital-publishing-solution/help/aem-mobile-end-of-life-faq.html)**
* **[Uso de Adobe PhoneGap Enterprise con AEM](/help/mobile/getting-started-aem-mobile-phonegap.md)**

>[!NOTE]
>
>Si no tienes experiencia en Adobe Experience Manager, puedes seguir [Introducción a AEM](/help/sites-deploying/deploy.md).
